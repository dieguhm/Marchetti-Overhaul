# 🌌 Marchetti Overhaul (MOverhaul)

**Marchetti Overhaul** é um AddOn definitivo de utilidades, qualidade de vida (QoL) e aprimoramento de HUD para o *The Elder Scrolls Online*. Ele traz melhorias visuais de navegação e salvaguardas cruciais para que a sua jornada em Tamriel seja mais fluida, segura e dinâmica.

---

## 🛠️ Módulos e Funcionalidades

O AddOn é composto por 4 módulos principais que podem ser ativados, desativados ou configurados de forma independente nas configurações do jogo:

### 1. 🧭 GPS Quest Arrow (Seta 2D de Quest)
*Nunca mais se perca em Tamriel buscando o caminho do objetivo.*
* **Como Funciona:** Exibe uma seta amarela no seu HUD que aponta diretamente para o objetivo da sua quest ativa, mostrando a distância exata em metros ou quilômetros.
* **Mecanismo Inteligente:** O AddOn utiliza um sistema avançado de cache que armazena a localização global real do objetivo quando você visualiza o mapa ou abre o diário de quests (`J`). Assim, mesmo que a quest esteja em outra zona e o jogo aponte a marcação nativa para uma porta de transição, a seta do Marchetti Overhaul continuará mostrando a distância real até o objetivo final.

### 2. 📍 Waypoint Navigation Arrow (Seta de Navegação Zygor-Style)
*A navegação rápida para marcações personalizadas no mapa.*
* **Como Funciona:** Uma seta secundária (estilo Zygor) que aponta para as marcações de waypoint que você coloca manualmente clicando com o botão direito no mapa mundial.
* **Facilidade:** Ideal para navegação rápida em pontos específicos que você deseja explorar no mapa sem precisar abrir o mapa a todo momento.

### 3. 🛡️ Gear Lockout (Prevenção contra Downgrade)
*Evite equipar acidentalmente equipamentos inferiores.*
* **Como Funciona:** Intercepta as ações de equipar itens. Caso você tente equipar um equipamento de qualidade inferior (ex: trocar um item lendário dourado por um roxo épico) por engano, o AddOn bloqueia a ação e exibe uma caixa de diálogo de confirmação pop-up.
* **Segurança:** Perfeito para proteger sua build final durante a limpeza e gerenciamento de inventário sob pressão.

### 4. ⚡ Overload Indicator (Sobrecarga de Feiticeiro)
*Indicador visual dedicado para a habilidade Sobrecarga (Overload).*
* **Como Funciona:** Exibe um indicador/alerta visual dedicado próximo ou sobre a barra de habilidades quando a Sobrecarga de Sorcerer (Feiticeiro) está ativa ou equipada, ajudando você a monitorar o estado da habilidade e evitar desperdício de Ultimate.

## 🚀 Como Instalar

1. Baixe os arquivos do repositório.
2. Copie a pasta `MOverhaul` para a pasta de AddOns do seu jogo (geralmente em `Documents/Elder Scrolls Online/live/AddOns/`).
3. Certifique-se de ter as seguintes dependências instaladas:
   * **LibAddonMenu-2.0**
   * **LibGPS** (opcional, para cálculo de distância global)

---

## ⚙️ Configurações In-Game

Acesse **Opções -> Addons -> MOverhaul** dentro do jogo para:
* Ativar/desativar cada módulo individualmente.
* Bloquear/desbloquear a posição das setas de quest e waypoint no HUD para arrastá-las com o mouse até o local desejado.
* Definir deslocamentos de ângulo para alinhamento perfeito.
